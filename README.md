# 🧠 Next Word Prediction using LSTM

A deep learning-based **Next Word Prediction** web application that predicts the next word in a sentence using an **LSTM (Long Short-Term Memory)** neural network.

The model is trained on text data and integrated with **Streamlit** to provide a simple and interactive web interface.
