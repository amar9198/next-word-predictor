# 🧠 Next Word Prediction using LSTM

A deep learning-based **Next Word Prediction** web application that predicts the next word in a sentence using an **LSTM (Long Short-Term Memory)** neural network.

The model is trained on text data and integrated with **Streamlit** to provide a simple and interactive web interface.

## 📌 Project Overview

Next Word Prediction is a Natural Language Processing (NLP) application that predicts the most likely next word based on the text entered by the user.

For example:

**Input:**

    I am going

**Predicted Next Word:**

    to

The LSTM model analyzes the input sequence and predicts the word that is most likely to come next.
